2021 年开始，最大的变化就是我把自己的远程工作转变成了团队作战的方式。通过之前在个人口碑上面的积累，接触到了更多的项目，同时也刚好有非常靠谱的伙伴，于是我们就决定继续向前一步，组建了现在的项目团队。

## 远程工作的起点

最初选择自由职业，是希望能够获得更大的时间和空间自由。从公司离职后，我开始独立承接 Web 开发项目，主要通过以下渠道获取客户：

- 个人网站展示作品
- GitHub 开源项目
- 朋友推荐
- 技术社区口碑

前三年是个人单打独斗的阶段，虽然自由，但也面临着项目不稳定、能力天花板等问题。

## 团队化的契机

当项目越来越多，一个人已经无法同时处理多个项目。这时候遇到了几位非常靠谱的伙伴：

| 角色 | 技能 | 合作年限 |
|------|------|----------|
| 前端 | React, Vue | 3 年 |
| 后端 | Node.js, Go | 2 年 |
| 设计 | Figma, Sketch | 2 年 |

> 一个人可以走得很快，但一群人可以走得很远。

## 经验总结

经过三年的团队化运作，总结出以下经验：

1. **信任是基础** — 团队成员之间必须充分信任
2. **流程是保障** — 即使是小团队也需要规范的开发流程
3. **沟通是关键** — 远程团队尤其需要高效的沟通工具和机制

```typescript
// 团队协作的核心代码：任务分配
interface TeamMember {
  name: string;
  role: "frontend" | "backend" | "design";
  capacity: number; // 每周可投入小时数
}

function assignTask(members: TeamMember[], taskHours: number): TeamMember | null {
  return members
    .filter((m) => m.capacity >= taskHours)
    .sort((a, b) => b.capacity - a.capacity)[0] ?? null;
}
```

三年又三年，磕磕绊绊到现在，是时候给自己和现在的团队一并再做一次总结了。
