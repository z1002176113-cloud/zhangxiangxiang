曾接受过两次关于这个话题的访谈，不过在技术社区分享时还是发现有很多不足，而且当时的时间太短，内容安排也不太合理，也有很多东西想完整地分享给大家，所以在这重新整理，也算是我将近三年自由职业的一个总结。

## 为什么要自由职业

离开公司的原因很简单：

1. **时间自由** — 不想朝九晚五，希望掌控自己的时间
2. **空间自由** — 不想固定在一个城市，想边旅行边工作
3. **选择自由** — 想选择自己感兴趣的项目和技术栈

## 如何开始

自由职业的第一步是建立个人品牌。我的做法是：

- 搭建个人网站展示作品
- 在 GitHub 开源项目
- 写技术博客积累影响力
- 在社区回答问题建立口碑

> 自由职业不是逃避工作的借口，而是对自我管理能力的极致考验。

## 收入来源

自由职业者的收入主要来自：

| 来源 | 占比 | 说明 |
|------|------|------|
| 外包项目 | 60% | 主要收入来源 |
| 技术咨询 | 25% | 按小时收费 |
| 开源打赏 | 10% | GitHub Sponsors |
| 课程/写作 | 5% | 技术社区收入 |

```javascript
// 自由职业者的收入计算器
function calculateIncome(projects, hourlyRate, hours) {
  const projectIncome = projects * 5000;
  const consultingIncome = hourlyRate * hours;
  return projectIncome + consultingIncome;
}

// 目标：月收入不低于 20000
const target = 20000;
console.log(`需要每月完成 ${Math.ceil(target / 5000)} 个项目`);
```

## 三年总结

回头看这三年，最大的收获不是收入，而是：

- **自律** — 没有人监督你，你必须自己管理自己
- **成长** — 接触不同领域的项目，技术广度和深度都在提升
- **人脉** — 认识了很多优秀的人，为后来的团队化打基础

如果给后来者一个建议：**先存够半年的生活费再开始**，这样你不会因为经济压力而接烂项目。
